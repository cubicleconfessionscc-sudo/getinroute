Vendor Management

Assign each trip to the right vendor and see vendor coverage across every route, driver, and vehicle.

What it does

Each transport operator gets its own profile — a short code, the locations or zones it covers, and its active status. Every vehicle and driver is linked to exactly one vendor, and each cab run records which vendor operated it at dispatch time. So the vendor stays on the trip even after the fleet is reshuffled.

How it helps

  • Keep every vehicle and driver tied to the vendor that operates them
  • Pick a vendor first when allotting a cab — only that vendor's vehicles appear
  • See which vendor runs each trip in the live board, trip list, and exports
  • Filter trips and spreadsheets by vendor for billing and audits

Built for

Operations and billing teams who run multiple transport partners and need to know exactly which vendor moved which employee.
