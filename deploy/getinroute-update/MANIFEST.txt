GetInRoute local build -> LIVE deployment package
=================================================
Created from the improved local build (D:\GetInRoute). Overlay these files
onto the same paths in the LIVE project (`D:\Default Project Portable\Project`
is the local snapshot of the live repo), then redeploy. See DEPLOY_NOW.md.

IMPORTANT
---------
* Back up the live database file BEFORE deploying.
* DO NOT copy any real `.env` file. Live secrets stay in your host's env
  variables (Railway dashboard / your CI secrets). `.env.example` is included
  only as a reference of what variables can exist.
* Nothing here touches your data folder. New tables are created automatically
  on first boot (`CREATE TABLE IF NOT EXISTS`) — safe on existing live data.

NEW / optional env vars for the host
------------------------------------
SIMULATE_GPS              =0  (or unset) -> GPS demo movement OFF; 1 = on.
GPS_HISTORY_COALESCE_MS   (default 5000)  live GPS throttle.
LOCATION_HISTORY_RETAIN_DAYS (default 3)  auto-purge age.
BACKUP_KEEP              (default 14)     backup snapshots to keep.
DB_PATH                  (optional)       where the live sqlite db lives.
UPLOAD_DIR / ALLOWED_ORIGINS (optional)   local defaults are fine unless changed.
